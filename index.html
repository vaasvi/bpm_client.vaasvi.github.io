Song BPM Fetcher Tool

This is a personal project for retrieving and analyzing BPM (beats per minute) data for music tracks.

About

The Song BPM Fetcher is a tool designed to automate the process of retrieving tempo information for large collections of songs.

Data Sources

This project uses tempo data from GetSongBPM.com, a comprehensive database of song tempos and musical keys.
